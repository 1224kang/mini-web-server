mini-web-server 3단계

이 페이지의 HTML, CSS, JS, 이미지는 모두 우리가 만든 C 서버가 보낸 것입니다.

JS 로딩 전…

  • /docs/ (하위 디렉토리의 index.html)
  • /docs (슬래시 없음 → 301)
  • /nope.html (404)

5단계: 동적 처리

  • /cgi-bin/add?a=1&b=2 (CGI: fork + exec 한 셸 스크립트)
  • /builtin/add?a=1&b=2 (내장 핸들러: 프로세스 없이 서버 안에서)
  • /form.html (POST 폼 → /cgi-bin/form 이 stdin 으로 받음)
  • /cgi-bin/env?x=1 (서버가 CGI 에게 준 환경변수)
